# Contribuindo com o Kognos

Obrigado por ajudar a construir uma plataforma de estudos melhor. **Kognos é um projeto proprietário; receber contribuições não o torna open source.**

## Como ajudar

1. Abra uma **Issue** descrevendo a melhoria, erro ou sugestão, sem divulgar dados privados, chaves de API ou informações de alunos.
2. Aguarde o alinhamento quando a mudança for grande.
3. Se você tiver acesso como colaborador, crie uma branch `feat/descricao-curta`, `fix/descricao-curta` ou `docs/descricao-curta`.
4. Implemente alterações pequenas, acompanhadas de testes/documentação, e execute `npm test` e, se possível, `npm run typecheck`.
5. Envie um **Pull Request** com contexto, testes feitos e possíveis impactos em privacidade/segurança.
6. A aprovação e o merge dependem do mantenedor `@PedroH0309`. Não faça push diretamente na branch principal.

## Regras do projeto

- Sem copiar código, questões de provas, aulas, imagens, marcas ou vídeos de terceiros sem licença/autorização compatível.
- Não inserir chaves (`nvapi-...`, `sb_secret_...`, tokens), `.env.local`, dados pessoais ou dumps de banco em commits/Issues/PRs.
- Evite armazenar dados de saúde/diagnósticos dos estudantes; preferências de acessibilidade devem permanecer voluntárias.
- Corrija bugs reais, não crie estatísticas falsas, chamadas de IA falsas ou botões sem ação.
- Siga o design system do Kognos, preserve acessibilidade e comportamento mobile.
- Para assuntos de segurança, siga `SECURITY.md`, não abra Issue pública com detalhes exploráveis.

## Termos das contribuições

Ao enviar um Pull Request, você declara que tem direitos para apresentar sua contribuição e concede ao mantenedor do Kognos uma licença **não exclusiva, mundial, irrevogável, perpétua e isenta de royalties** para usar, modificar, integrar, reproduzir, distribuir, sublicenciar e comercializar **a contribuição submetida** como parte do Kognos, inclusive em produtos proprietários e versões futuras. Você mantém a titularidade de suas contribuições originais, salvo acordo específico em contrário. O mantenedor não é obrigado a aceitar qualquer Pull Request.

Se você não concordar com esses termos, envie somente uma sugestão ou dúvida em Issue, sem anexar código ou conteúdo protegido. Um acordo jurídico específico poderá ser usado para contribuições substanciais.

## Permissões

O trabalho de colaboração é autorizado somente no escopo definido no arquivo `LICENSE`. Contribuir com código não autoriza publicar sua própria versão do Kognos ou revender a plataforma.

# Kognos Web

Next.js App Router/TypeScript. Inicie a partir da raiz do repositório com `npm install` seguido de `npm run dev`.

Os primeiros fluxos incluem onboarding funcional, experiência local, autenticação Supabase (configurável), persistência de preferências e tutor NVIDIA protegido por autenticação e quota. Não há simulados, redação ou dashboard de desempenho com dados reais nesta versão.


Kognos v0.4: veja `../../docs/KOGNOS_SPRINT_04_SUPABASE.md` para configurar @supabase/server, JWKS e RLS.

Kognos v0.5: `design-system.css` contém os novos tokens e os estilos finais das telas existentes. A configuração segura da NVIDIA pode ser feita via `CONFIGURAR_API_NVIDIA.bat` (raiz). A conversa informa sobre o provedor e não pede autorização a cada mensagem.

# Kognos: Português, Inglês e Redação (Etapa 4)

Esta etapa adiciona dez oficinas didáticas originais. Português: interpretação com evidência, gramática contextual e conectivos/coesão. Inglês: leitura, verbos modais e referências pronominais. Redação: recorte temático, argumentos, revisão coesiva e proposta de intervenção.

Os textos são autorais; não são questões de provas oficiais. O feedback objetivo serve apenas ao exemplo selecionado. Rascunhos ficam na sessão da interface, não recebem nota automática e não alimentam o mapa de domínio. A prática avaliada permanece em Evolução da habilidade.

As oficinas aparecem por correspondência específica de assunto no catálogo e nas Trilhas. Tópicos sem atividade especializada mantêm o explorador geral. Não há migrações, endpoints ou chaves novas.

Validação: npm test; npm run test:content-db; npm run test:design; npm run typecheck; npm run build. Realizar também inspeção visual no celular. Próxima etapa independente: História, Geografia, Filosofia e Sociologia.
